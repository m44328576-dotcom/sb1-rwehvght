# PixelMarket - منصة تداول البكسلز الرقمية

منصة متكاملة لشراء وبيع وتداول مليون بكسل رقمي مع نظام تسعير ديناميكي وتحقق من الملكية عبر البلوك تشين.

## المميزات الرئيسية

### 1. شبكة البكسلز (1,000,000 بكسل)
- شبكة 1000×1000 بكسل قابلة للتداول
- كل بكسل يمكن استخدامه لعرض إعلانات أو NFTs
- واجهة تفاعلية مع إمكانية التكبير والتصغير والتنقل

### 2. نظام التسعير الديناميكي
- التسعير يتغير حسب العرض والطلب
- خوارزميات متطورة تأخذ في الاعتبار:
  - عدد مرات البيع
  - السيولة في السوق
  - حجم التداول
  - تقلبات السوق

### 3. نظام الدفع بالعملات الرقمية
- دعم محافظ رقمية متعددة (ETH, BTC, USDT, BNB)
- إنشاء محافظ آمنة مع تشفير المفاتيح الخاصة
- معاملات فورية وآمنة

### 4. نظام العمولات الذكي
- عمولة 5% على المبيعات الأولية من الموقع
- عمولة قابلة للتعديل للمعاملات بين المستخدمين
- حساب تلقائي للعمولات والأرباح الصافية

### 5. التحقق عبر البلوك تشين
- كل معاملة تحصل على hash فريد
- تتبع كامل لتاريخ الملكية
- شفافية تامة في المعاملات

### 6. لوحة تحكم متقدمة
- عرض البكسلز المملوكة
- إحصائيات الأرباح والمصروفات
- سجل المعاملات الكامل
- تحليل السوق الفوري

## البنية التقنية

### قاعدة البيانات (Supabase)
- **profiles**: بيانات المستخدمين والإحصائيات
- **pixels**: معلومات 1 مليون بكسل
- **transactions**: سجل المعاملات مع التحقق
- **wallets**: المحافظ الرقمية للمستخدمين
- **price_history**: السجل التاريخي للأسعار

### الأمان
- Row Level Security (RLS) على جميع الجداول
- تشفير المفاتيح الخاصة
- مصادقة آمنة عبر Supabase Auth
- حماية من SQL Injection

### التقنيات المستخدمة
- **Frontend**: React + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Icons**: Lucide React

## التثبيت والإعداد

### 1. متطلبات النظام
```bash
Node.js 18+
npm or yarn
```

### 2. التثبيت
```bash
npm install
```

### 3. إعداد قاعدة البيانات
قم بإنشاء ملف `.env` في المجلد الرئيسي:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

قاعدة البيانات Supabase جاهزة ومُعدة بالكامل مع:
- جميع الجداول والعلاقات
- سياسات الأمان (RLS)
- الفهارس للأداء الأمثل
- دوال المساعدة

### 4. تشغيل المشروع
```bash
npm run dev
```

### 5. البناء للإنتاج
```bash
npm run build
```

## كيفية الاستخدام

### للمستخدمين الجدد
1. **التسجيل**: أنشئ حساباً جديداً باستخدام البريد الإلكتروني
2. **المحفظة**: أنشئ محفظة رقمية لبدء التداول
3. **الشراء**: تصفح شبكة البكسلز واختر ما تريد شراءه
4. **التداول**: بع البكسلز الخاصة بك أو احتفظ بها للاستثمار

### للبائعين
1. اختر البكسل الذي تملكه
2. حدد السعر والمحتوى (إعلان أو NFT)
3. ضع رابط المحتوى إذا أردت
4. أطلق البكسل للبيع

### للمشترين
1. تصفح السوق وابحث عن البكسلز المعروضة للبيع
2. اضغط على البكسل لعرض التفاصيل
3. راجع السعر والعمولة
4. أكمل عملية الشراء

## خوارزمية التسعير

```javascript
السعر الجديد = السعر الحالي × (1 + عدد المبيعات × 0.05) × (1 + معامل السيولة) × تقلبات السوق
```

حيث:
- **معامل السيولة**: يعتمد على عدد المبيعات السابقة
- **تقلبات السوق**: عامل عشوائي صغير (±5%)
